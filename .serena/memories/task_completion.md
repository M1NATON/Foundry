# Завершение задачи

1. При изменении контракта: `pnpm --filter @foundry/shared-types build`.
2. Запустить `pnpm test`.
3. Запустить `pnpm typecheck`.
4. Запустить `pnpm build`.
5. Для Prisma-изменений выполнить generate и нужную migration.
6. Для queue/DB/browser поведения вручную проверить затронутый поток.
7. После исходников выполнить `graphify update .`.
8. Сообщить о пропущенных проверках и существующих отдельно от новых ошибках.
